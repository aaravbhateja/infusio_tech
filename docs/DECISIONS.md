## D-001: Project Structure Initialized

- **Date:** 2026-09-15
- **Status:** ✅ Accepted
- **Context:** Starting a professional website rebuild from a Shopify-based business site.
- **Decision:** Initialize a documentation-first project structure with phases: Research → Audit → Strategy → Design → Architecture → Development → Testing → Deployment.
- **Rationale:** Establishing governance and documentation before any design or code work prevents scope creep, ensures alignment, and mirrors professional agency workflows.
- **Alternatives Considered:**
  - Jump straight into design — rejected; risks building the wrong thing.
  - Minimal docs with口头 alignment — rejected; no audit trail for decisions.
- **Impact:** Adds upfront time but reduces rework risk significantly.
