## Decision Criteria

When selecting the tech stack, we will evaluate:

1. **Business fit** — Does it support the required e-commerce features?
2. **Performance** — Page speed, Core Web Vitals, mobile performance
3. **SEO** — Server-side rendering, structured data, URL control
4. **Maintainability** — Can the client's team manage it post-launch?
5. **Scalability** — Can it grow with the business?
6. **Cost** — Hosting, licensing, operational costs
7. **Timeline** — Can we ship within the project deadline?
8. **Ecosystem** — Community, plugins, integrations available
