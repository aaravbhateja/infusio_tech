## Working Principles

1. **Phase-by-phase** — each phase ends with a report and waits for client approval.
2. **No assumptions** — we verify business facts before proceeding.
3. **No unauthorized changes** — nothing is modified or deleted without approval.
4. **Documentation-first** — decisions and requirements are always recorded.
